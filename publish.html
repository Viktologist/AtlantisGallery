Share a Model

Connect Atlantis Gallery MCP once. When a modeling task is ready, ask your Atlantis assistant to share it, then confirm the files you want to make public.

Connect to Codex on Windows

Install Python 3.11 or later and Git for Windows with Git Credential Manager. Run these commands in PowerShell, then restart Codex.

git credential-manager github login
git clone https://github.com/zhxx1987/AtlantisGallery.git
Set-Location AtlantisGallery
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r publisher/requirements.txt
codex mcp add atlantis-gallery -- (Resolve-Path .\.venv\Scripts\python.exe).Path (Resolve-Path .\publisher\server.py).Path

For another MCP client, use the virtual environment’s Python executable as the command and the absolute path to publisher/server.py as its argument. The connection uses stdio.

Share from an Atlantis modeling chat

Share this asset to Atlantis Gallery. Prepare a submission from the final model, textures, motion files, modeling code, and the work order I approve. Show me every file before publishing.

Review the list from prepare_gallery_upload. After you approve the public upload, publish_gallery_asset uploads the files using your GitHub account and opens a pull request. Once Gallery maintainers merge it and GitHub Pages updates, your work link is live. The Gallery owner publishes directly.

Describe the export

The assistant writes submission.json next to the export. All paths are relative to that file. Supply an English title, your display name, a rendered thumbnail, and the files you want to share.

{
  "schema": "atlantis-gallery-submission/1",
  "slug": "hinged-cabinet",
  "title": "Hinged Cabinet",
  "creator": "Your Display Name",
  "model": "cabinet.usd",
  "thumbnail": "preview.webp",
  "previewFiles": ["textures/oak.png"],
  "modelFiles": ["scene.usd"],
  "interaction": "interaction.json",
  "motionFiles": ["motion/cabinet.py"],
  "sourceFiles": ["modeling/build_cabinet.py"],
  "workOrder": "work-order.json"
}
  • List dependencies required by the web preview in previewFiles, with the paths the model expects. Use a browser-ready USD or GLB export.
  • Use modelFiles for additional USD layers and motionFiles for the original motion scripts. These join the model and preview dependencies in the model download.
  • List the final modeling code for every part and its required data in sourceFiles.
  • Include workOrder only if you approve the complete JSON for public download. Review it for private information before sharing.
  • Provide interaction for browser controls. It maps part paths to joints, buttons, and emit events. The existing microwave uses the shared Python profile. New Python profiles require a Gallery adapter. View the interaction format.
